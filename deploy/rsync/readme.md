This is for setting up rsync auto copy feature to copy all files from your machine to the server.

# Setup Rsync auto copy
We need to store server information to automate future copy sessions.

1. Open terminal and go to the folder this file is in.
2. Run `bash rsync-setup.sh` and fill in the information it asks.
3. Run `bash rsync-server.sh` and it should copy all the files to your server.
4. Done, server should now have all the files and next step is to start the server.
